# Heavenly Couture Demo

A clickable storefront demo for Heavenly Couture: a California-inspired boutique with jewelry, clothing, a beach shop and a custom chenille sweatshirt builder.

## Pages

- `index.html` (Home)
- `shop.html` (Shop, with filters)
- `product.html` (Product detail)
- `design.html` (Design your own sweatshirt)
- `visit.html` (Visit us)
- `checkout.html` (Checkout)

This is a design demo. The bag, checkout and forms are not connected to a store. The production site will run on Shopify.

## Viewing it

Open `index.html` through any static web server, or turn on GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main` / root).
